复制给你的 Agent

一段指令完成接入

把下面这段内容发给你正在使用的 AI 工具，它会帮你完成 Maker MCP 安装和本地项目初始化；Codex、Cursor、ClaudeCode 都只是可选示例。

一、安装 Maker MCP
npx -y @taptap/maker install --ide codex,cursor,claude
部分 Agent 安装后，可能需要重新启动

二、初始化项目
选择一个空白的本地目录作为项目目录，在目录中执行：
npx -y @taptap/maker init
