# 平行陪伴者参考摘要与采用边界

来源：[Shellingfordh LiangLiao read.md](https://github.com/Shellingfordh/LiangLiao/blob/main/read.md)。本文件保留其对本项目有用的产品启发和明确的接入边界；远端原文仍是完整参考来源。

## 可采用的核心观点

参考文档将体验定义为一个会继续生活的人，而不是等待输入的聊天机器人。它提出的有效产品循环是：观察角色所在的世界，发现她的当前状态，依据正在发生的事件交流，经历留下痕迹，用户离开后世界继续，下一次回来时看见变化。

这强化了本项目已有的三项原则：当地时间不是单纯 UI；延迟回复是角色真实可用性的结果；对话必须从 Lua 确定的生活事件事实出发。它也强调小世界可以拥有高生活密度，不需要用大地图、任务或数值养成制造陪伴感。

## 已纳入本项目的内容

- M4 的状态包把时间、地点、事件、人物状态、场景和近期生活痕迹绑定为同一份事实。
- 角色档案和 2.5D 场景中的便签、咖啡、唱片或雨伞，使用户回来时能观察到一条最近生活线索。
- 三段独立人生让城市和关系起点形成有限、可切换的平行时间线。
- M4 的验收以“回来时能解释她刚刚发生了什么”为目标，而不是增加背景数量本身。

## 明确延后

远端参考中的可进入完整 3D 世界、玩家物品进入房间、自由探索和复杂角色移动不属于 M4。当前阶段只保留 `future3D.sceneRef` 与 `anchorId`，以后在真机性能、模型骨骼和动画导入均验证通过后再接入。

运行时仍不调用 LLM；所有时间、事件、记忆、状态和场景选择由 Lua 与本地存档决定。任何后续生成式能力只能在既定事实之外做构建期资产生产或受控文本润色。
