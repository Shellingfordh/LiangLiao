========================================
3. 架构与限制
========================================

引擎：UrhoX

核心能力
- AI Native 引擎
- PBR / 动态多光源 / 动力学解算
- 内置联网对战
- TapTap 云原生托管

限制
- ❌ 不提供源码导出
- ❌ 不生成独立运行包
- ❌ 不交付底层引擎代码

开发模式
- 云端 Maker Studio（需登录）
- 本地 MCP（推荐）

========================================
4. 项目建议
========================================

约束
1. 必须使用 TapTap Maker
2. 只能在 TapTap 生态内发布
3. MCP 是本地开发的唯一路径

建议
1. 优先使用 MCP 本地开发
2. 考虑叙事向游戏（山田凉/后藤一里）
3. 使用 Tripo Studio 生成 3D 模型
4. 借鉴 mattpocock/skills 叙事工作流

下一步
1. npx -y @taptap/maker install
2. npx -y @taptap/maker init
3. 创建第一个简单场景
4. 集成 Tripo 3D 模型
