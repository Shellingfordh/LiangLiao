## 2. 赛道与组队

### 2.1 方向赛道（必选其一）

每支队伍必须选择一个方向赛道。方向赛道不限工具，用你顺手的任何 3D / 世界构建软件都行。

| # | 赛道 | 方向说明 | 接受形式 |
| --- | --- | --- | --- |
| 01 | 🎮 游戏（Games） | 剧情向 / 互动解谜 / 情感向体验 | 网页、App、独立作品 |
| 02 | 🎬 影视 / 视效（Film / VFX） | 短片、动画、VFX、3D 导演台 workflow | 视频、App、Web、独立作品 |
| 03 | 🥽 VR / XR / AR | VR 体验、移动 AR 滤镜、WebAR、空间与沉浸式体验 | App、Web、独立作品 |
| 04 | 📱 应用（Apps & AI-Native Tools） | 网页、AI 原生产品、创作工具、互动应用、小程序 | 网页、App、独立作品 |
| 05 | 🛠️ 实体设计（Physical Design） | 3D 打印、产品设计、装置、雕塑、沙盘，从数字到物理的制造 | 实体、模型文件、3D 打印 |

### 2.2 工具赛道（可选 0–3 个）

工具赛道来自 Tripo 的合作伙伴。选择工具赛道即有机会角逐对应工具的单项奖，但参赛作品必须真实使用该工具，否则取消该工具赛道参评资格。

当前工具赛道合作伙伴：**Tripo、PICO、Heygears、World Labs**（更多即将公布）。

> 同一作品可同时获得方向赛道奖项 + 多个工具赛道奖项，奖项可叠加。

### 2.3 组队规则

- 支持个人参赛，也支持 2–3 人组队。
- 鼓励技术（全栈 / AI）+ 创意（设计师 / 艺术家）的跨界混搭。
- 每支队伍需在报名时确认队长，由队长统一提交作品。
- 可以在官方社群内主动寻找组队。

**组队模板：**

```text

我是【你的名字 / 昵称】，擅长【你的技能，如：Unity 开发 / 3D 建模 / UI 设计 / 视频剪辑】。
想选【赛道，如：游戏赛道】，做一个关于【你的 idea 一句话，如：给童年的自己的一场梦境冒险】的作品。
目前缺【需要的队友方向，如：一个会写 shader 的程序 / 一个美术】，1–3 人小队，有意向的直接私信我！🎮
```

## 3. 提交要求

### 3.1 按赛道交付物要求

不同赛道的作品形态差异较大，因此交付物要求按赛道分组说明。所有赛道均可额外提交公开开发日志（Build Log）作为加分参考。

#### 影视 / 视效赛道（Film / VFX）

| # | 交付物 | 是否必交 | 说明 |
| --- | --- | --- | --- |
| 1 | 视频成片 | 必交 | 完整可观看的短片 / 动画 / VFX 作品。形式可以是完整短片、动画片段、VFX 镜头合集等。 |
| 2 | 工程文件 | 必交 | 项目源文件（如 Blender / Unreal / After Effects / Maya / Houdini 等工程文件），展示制作流程与技术实现路径。 |
| 3 | 视频故事说明 | 必交 | 一段文字说明，包含作品的故事背景、创作意图、核心技术亮点与制作流程简述。 |

#### 游戏 / VR / XR / AR / 应用赛道

| # | 交付物 | 是否必交 | 说明 |
| --- | --- | --- | --- |
| 1 | 完整可玩 Demo | 必交 | 评委可游玩、可试玩的完整 Demo。形式可以是 Web / H5 / App / 可执行文件等。 |
| 2 | 演示录屏视频 | 必交 | 约 1–2 分钟的 Walkthrough，带用户走进这个世界（不是预告片剪辑）。需包含核心功能演示，建议有语音解说。 |
| 3 | 视觉资产看板 | 必交 | 3 张以上核心场景的高清截图 / 动图，包括关键静帧、多视角展示图（multi-view）、环境画面等。 |

#### 实体设计赛道（Physical Design）

| # | 交付物 | 是否必交 | 说明 |
| --- | --- | --- | --- |
| 1 | 实体作品完整展示 | 必交 | 实物原型 / 产品 / 装置 / 雕塑的完整呈现，让评委看到你做出来的东西。好的实物展示能让评委和合作伙伴（如 Heygears 黑格）更直观地理解你的作品。 |
| 2 | 多视角展示（multi-view） | 必交 | 正面、侧面、背面、顶部、底部，以及关键细节特写，让评委看清产品全貌与工艺。 |
| 3 | 运作演示视频 | 必交 | 如果作品有机械结构、运动部件或交互功能，拍摄一段短视频展示它实际运作的样子。 |
| 4 | 使用场景照 | 必交 | 把原型放到真实使用环境中拍摄，展示它与世界的关系。 |

#### 通用可选（全赛道）：公开开发日志（Build Log）

参赛期间在社媒公开发布的开发进度日志。写得起劲的，官方会帮你置顶扩散，也可作为评审加分参考。

## 7. 注意事项

### 7.1 行为规范

- **尊重原创**：未经允许请勿转载、使用他人作品。允许使用开源模型、前端脚手架及各类生成式 AI 工具，但核心业务逻辑和资产串联必须在比赛期间完成。
- **理性表达**：黑客松是开放、包容的创作空间，请对自己的言论与行为负责，共同维护安全、合法、开放包容的活动环境。
- **拒绝歧视**：请抵制任何形式的歧视性语言与行为，包括但不限于性别、国别、种族、年龄、是否健全，让不同背景的伙伴都能在这里自由表达、安心创作。
- **友善沟通**：碰撞灵感时难免有分歧，用友善与沟通代替对立。

### 7.2 关于二次开发

允许使用开源模型、前端脚手架（如 Cursor、v0、Next.js）以及各类生成式 AI 工具。如果你在比赛前已有一个 idea 或简单尝试，在比赛中基于这个想法做出了可以展示的作品，不算二次开发。

如果你在黑客松开始前，无论以什么身份，完成了同一项目的代码、开发或搭建，则属于二次开发，须在提交时主动申报改造基础与新增内容。未申报或申报不实、被查实者将取消评审资格。

> 评委仅对「工作增量」进行评价，即只对创作期内新增的功能与创新计分。

### 7.3 版权与知识产权

- 所有参赛作品的知识产权归原作者或相关权利人所有。
- 参与本次活动即视为参赛者同意授予 Tripo AI 免费、非独占的使用许可，Tripo AI 可为本次活动及 Tripo AI 平台相关宣传推广之目的，对参赛作品进行展示、传播和使用。
- Tripo AI 在使用参赛作品时，将尽合理努力保留作者 ID、用户名等来源信息，以体现作品归属。
- AIGC 类作品请注意内容来源及版权归属，请勿使用未经授权的媒体内容（包括但不限于图片、视频、音频、词作）。

## 8. 实现验证要求（本作品额外增加，v2 已更新）

> 本节曾包含自由移动、摇杆、镜头旋转与点击角色对话等旧“三位 NPC 小镇”方案的要求，现已**真实废弃**，不得作为本项目的实施或验收依据。当前权威实现要求见 `docs/2026-09-15-parallel-companion-design.md`：聊天优先、固定镜头 3D 状态窗、角色不可由玩家自由操控。自由移动若未来探索，只能作为不影响核心体验的后期可选扩展。

提交前必须按顺序完成以下验证，未通过项不得进入下一项：

1. **游戏是否能正常开始**
   - 预览 / 实机测试入口可正常进入主场景。
   - 角色模型正确加载，场景无黑屏 / 白屏 / 崩溃。
2. **操作是否符合预期**
   - PC / 手机：用户可在聊天主界面查看固定镜头状态窗、阅读当地时间与含蓄状态，并发送消息或使用演示预置消息。
   - 不提供 WASD、虚拟摇杆、自由镜头旋转、缩放或直接操控角色。
   - 核心聊天动作在 2 次点击内可完成，无菜单卡死。
3. **成功、失败和重新开始是否完整**
   - 成功：玩家可触发至少一个情感反馈事件（想你 / 生日 / 下雨 / 日记）。
   - 失败：定义明确的失败条件与提示（如网络超时、存档损坏、模型加载失败），并有“重试 / 重新开始”入口。
   - 重新开始：支持从头开始 / 回到上一次存档点，且状态恢复一致。
4. **画面在目标设备上是否清楚**
   - 目标设备：实机测试手机 + PC 预览。
   - 角色与 UI 在真机分辨率下可读、无严重锯齿 / 掉帧。
   - 3D 模型面数控制在移动端可接受范围（建议 `face_limit <= 5000`）。
5. **是否存在卡住流程的问题**
   - 从进入到触发首个事件，无死循环、无无限 loading、无对话卡死。
   - 离线时间检测准确，不会出现事件不触发或重复触发导致流程中断。
   - 所有必交物（Demo / 录屏 / 截图）可在流程内正常生成。

## 9. 常见问题（FAQ）

**Q1. 不去线下也能获奖吗？**
能。所有参赛作品都可角逐全球线上奖池；线下 Demo Day 如果到场，还能同时角逐所在赛区的线下奖池，现场颁发。

**Q2. 我可以只用 Blender / UE / 其他工具吗？**
可以。方向赛道不限工具；若想争工具单项奖，需真实使用 Tripo、PICO、Heygears 或 World Labs。

**Q3. 个人可以参加吗？还是必须组队？**
个人、2–3 人小队都行。学生、设计师、独立开发者、艺术家，都欢迎。

**Q4. 可以同时参加多个赛道吗？**
每支作品必须选择一个方向赛道，可同时选择 0–3 个工具赛道。同一作品可同时获得方向赛道奖和多个工具赛道奖。

**Q5. 提交后还能修改吗？**
