# 送给你这个回来的人 产品需求文档

## 1. 产品定位

《送给你这个回来的人》是 Tripothon S1 的原创平行陪伴体验。用户与生活在另一座城市、遵循同一真实时间线的若夕聊天；她有自己的日程、地点、关系和生活事件。聊天是主界面，状态窗让用户观察她此刻正在生活的世界。

产品不追求开放地图、数值养成或即时回复。核心体验是：用户观察她的状态，依据此刻生活事件交谈，离开后她继续生活，再回来时看见时间和经历留下的变化。

## 2. 产品原则

- 只使用原创角色、场景、文本、音乐和视觉资产。
- Lua 决定时间、状态、事件事实和存档；回复只能表达既定事实。
- 角色按城市当地时间生活，允许睡眠、忙碌和延迟回复。
- 聊天优先；3D 或 2.5D 状态窗是固定镜头的状态展示，不做开放世界。
- 运行时不依赖 LLM、真实天气、新闻、Tripo 或 Marble。

## 3. 核心循环

```text
观察当前生活状态
  → 发送消息
  → 依据事件事实等待或回复
  → 共同经历留下记忆
  → 用户离开
  → 角色按当地时间继续生活
  → 用户回来并发现变化
```

## 4. 已有能力

M0 至 M3 已建立：原创角色状态窗、真机视觉链路、当地时间和 DST 推导、事件事实驱动的延迟回复与记忆、上海/成都/洛杉矶/伦敦四城，以及城市和关系起点档案。

## 5. M4 可感知的平行人生

M4 目标是让“另一座城市里正在生活”从一条状态文案变成可观察、可重返的体验。

### 5.1 人生入口

冷启动直接恢复最近打开的一段人生并进入聊天。用户点击设置入口后，可查看档案、切换已有的人生，或以城市和关系起点创建新故事。最多三段独立人生；每段分别保存聊天、事件、记忆和当前生活痕迹。

### 5.2 角色档案

角色档案是只读信息页，展示城市、当地时间、身份、关系起点、近期生活线索与当前状态。它不再兼任换档案选择层。

### 5.3 场景与生活痕迹

四城各制作居所、工作场所、公共停留处、街区或通勤过渡处四张原创 4:3 静帧，共 16 张。每个场景状态包统一提供背景、色温、主光、人物站位、接地阴影、微动和生活痕迹锚点。

背景采用 2.5D：静态场景图上叠加不可点击的 2D 定位物，如便签、咖啡、唱片或雨伞。每段人生只显示由最近关键事件确定的一条当前痕迹；未来 3D 场景将复用同一锚点，不改变事实或存档语义。

### 5.4 人物动作边界

M4 先采用静态人物与不依赖骨骼的细小微动。骨骼动作必须在 GLB、MDL 骨骼和动画轨道、以及 Maker 真机播放均通过验证后才可接入；失败时回退为无骨骼微动，不影响 M4 交付。

### 5.5 M4 验收

- 三段人生互不串写，冷启动恢复最近人生。
- 档案、对话和状态窗始终引用同一城市、关系、事件和生活痕迹。
- 16 个场景不复用错误背景，人物光影与接地阴影能融入对应场景。
- 重进与切换后不出现旧城市、旧场景或旧痕迹。
