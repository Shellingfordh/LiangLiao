## 二、日文维基（https://ja.wikipedia.org/wiki/ぼっち・ざ・ろっく!）

### 結束バンド 概况
- 乐队名「結束バンド」（中国俗称 纽带乐队/团结Band/结束乐队），リョウ命名，虹夏最初想改名但沿用。
- 活动据点：下北沢 Live House「STARRY」（店长：伊地知星歌，虹夏之姐）。
- 成员姓氏（後藤/伊地知/山田/喜多）均源自乐队「ASIAN KUNG-FU GENERATION」成员姓氏；**成员生日为对应成员生日的反转（例：後藤正文12/2 → 後藤ひとり2/21）**。
- 所属唱片公司：ストレイビート（STRAY BEAT）。
- ひとり作词（曲风偏负向），リョウ作曲（几乎一言堂定方向）。

### 後藤ひとり（ごとう ひとり）
- 声：青山吉能
- 誕生日：2月21日 / 身長：156cm / 体重：50kg / 血液型：O型
- 本作主人公。リードギター・作詞担当。秀華高校1年2組（2年級時表記有争议：4卷2年3組 vs 6卷2年C組，后作者确认为2年3組）。
- 昵称「ぼっちちゃん」（リョウ取名）。住在横浜市金沢八景駅付近。
- 粉发、右侧水蓝/黄两个立方体型发夹、常穿ジャージ（运动服）、家在暗处壁橱弹吉他。
- 极度社恐：对陌生人几乎无法搭话、不直视对方、结巴；压力大时面部崩坏、躲垃圾箱/纸箱。
- 每天练吉他6小时以上约3年，solo实力达专业级；网名「ギターヒーロー（guitarhero）」在投稿网站人气，订阅者第1卷时3万人、第4卷时10万人。
- 承认欲求强，被夸就得意忘形；妄想癖强。美少女（但自己不自觉）。

### 伊地知虹夏（いじち にじか）
- 声：鈴代紗弓
- 誕生日：5月29日 / 身長：154cm / 体重：48kg / 血液型：A型
- ドラム担当。下北沢高校2年→3年。乐队的领导者/まとめ役，常识人担当（吐槽役）。
- 水玉リボン（波点蝴蝶结）为标志。幼时母亲意外去世，父亲工作常不在家，与姐姐星歌两人生活。
- 为圆「姐姐的live house更出名」的梦组建結束バンド。兼任経理、设计（乐队logo/CD封面）、视频编辑。
- 性格温和体恤成员；也常对リョウ用暴力式吐槽（德国suplex等，动画中未呈现暴力）。
- 最早发现「ギターヒーロー=ひとり」。

### 山田リョウ（やまだ リョウ）
- 声：水野朔
- 誕生日：9月18日 / 身長：163cm / 体重：50kg / 血液型：AB型
- ベース・作曲担当（TV动画版亦担当コーラス）。下北沢高校2年→3年。
- 无口・无表情・朋友少；言行突发奇想，被称「変人」反而高兴；偶尔说出切中要害的建议。
- ひとり的评价：不是コミュ障，是「喜欢一个人待着」。兴趣：古着屋巡り、廃墟巡り。私下在家看电影。
- 对音乐/乐器讲究，谈起来会变健谈；怕危险游乐设施（绝叫マシン），虹夏说其「其实是胆小鬼」。
- 信念「個性を捨てたら死んでるのと一緒」。曾因乐队成员放弃个性走卖线路线而退出（前乐队后解散）。
- 家境富裕（父母经营医院），但零用钱几乎全花在乐器上，常借钱甚至吃杂草果腹。生活能力为零，常受虹夏照顾。
- 学业：考试可0分，但临时抱佛脚可拿近满分（曾放话要考东大），但不用就忘。
- 高校毕业后不升学，打算做自由职业者专心作曲。
- 最初设定是「不思議ちゃん系可爱角色」，与现行设定差异大。

### 喜多郁代（きた いくよ）
- 声：長谷川育美
- 誕生日：4月21日 / 身長：158cm / 体重：44kg / 血液型：A型
- ギター・ボーカル担当。秀華高校1年5組（2年級后与ひとり同班）。
- 自称「人と関わるのが大好き」，社交型陽キャ，常是话题中心。外貌可爱、爱打扮逛街、SNS重度用户（虹夏说其「中毒」）。
- 因憧憬リョウ而加入結束バンド，本不会弹吉他，初次live前临阵脱逃；后经ひとり和解重新加入，拜ひとり为师。
- 对「郁代」名字有自卑（与「来た、行くよ」同音），自我介绍只报姓、希望被叫姓。
- 唱歌出色（卡拉OK强项）、运动神经好、学业中等。
- 文化祭live时为出机材故障的ひとり现场即兴拖延时间，成长显著。
