## 运行时契约

1. `occurrenceKey` 仍由城市、当地日期和模板 id 构成；同城同日重算与读档补齐卡片字段都不改变它。
2. 状态窗的事件注释在关键事件进行中显示“线索”；匹配到已声明的自然发问时，模板给出固定回答。未匹配的自由输入以“我只能先确认”明确回退到同一事实，不能伪称精确理解。
3. 生命周期从关键事件结束开始。该人生槽中的 M7 痕迹不会被普通日程覆盖；切换人生、冷启动和重复刷新都继续使用同一 `occurrenceKey`。画面仅在痕迹绑定的场景显示，档案始终保留同一事件标题。
4. 本阶段复用既有 16 张原创背景和现有 2D 痕迹贴图；没有新增 Marble 静帧或 Tripo 模型，因此不增加 `resources.json` 条目。

给每位试玩者一段已进入关键事件时窗的人生，不告诉事件标题。请其完成“你觉得她正在经历什么？你从哪里看出来？回来后哪个东西还在说明这件事？”三问。记录其是否能把**线索、回复、档案/痕迹**指向同一事件，而不是仅说出地点或背景。样本达到 5–8 位后，按城市统计：无法回指时优先改卡片线索或固定措辞，不增加背景图凑覆盖率。
